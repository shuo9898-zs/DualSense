# Third-party and release notes

The code interfaces with CARLA/Unreal Engine, SUMO/TraCI, Pygame and Beam Eye Tracker. Their software and assets have independent terms. The vendor SDK and simulator binary package are excluded.

Existing copyright/authorship/AI-assistance comments are retained. Some scripts explicitly mention Assistant or GitHub Copilot; the release does not certify that all code predates AI-assisted coding.

No repository-wide license was present in the prior snapshot. This update does not choose a license for the authors. Licensing and third-party attribution require author review before claiming unrestricted reuse or redistributing assets. No participant data is released.
